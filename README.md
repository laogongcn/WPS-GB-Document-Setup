# WPS国标公文安装包

一键安装方正公文四款字体 + WPS国标公文模板。

## 下载

👉 直接下载：[WPS国标公文安装包.exe](https://github.com/laogongcn/WPS-GB-Document-Setup/releases/latest)

## 使用方法

1. 双击 `WPS国标公文安装包.exe`
2. 按向导提示完成安装
3. 打开WPS文字即可使用

## 功能

- 自动安装方正公文仿宋/黑体/楷体/小标宋字体
- 自动配置WPS国标公文模板
- 支持控制面板卸载

## 从源码编译

1. 安装 [Inno Setup](https://jrsoftware.org/isinfo.php)
2. 下载 `ChineseSimplified.isl` 放入 `Languages` 文件夹
3. 打开 `WPS_GB_Setup.iss`，按 F7 编译
